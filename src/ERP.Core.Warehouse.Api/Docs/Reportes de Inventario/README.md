# Reportes de Inventario

Carpeta de documentación para los endpoints de reportes de inventario.

Endpoints disponibles (base `api/v1/companies/{company_id}/modules/{module_code}/reports/`):

- `stock-daily`
- `physical-count`
- `inventory-movement`
- `inventory-turnover`
- `outputs-line-equipment`
- `outputs-detail-by-equipment`
- `outputs-consolidated-by-equipment`
- `period-inventory`
